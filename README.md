# todge. 

Terminal Dodge.

<img width="1265" height="679" alt="todge" src="https://github.com/user-attachments/assets/cd9e941e-db62-4103-90c8-6301c0c700bd" />

You are `@`.

`■`s are falling on you.

Dodge `■`s to survive. 

`■`s speed up as the game progresses.

Survive as long as you can.

## Setup

Using [cargo](https://rust-lang.org/learn/get-started/):
```bash
cargo run
```

## Controls
* `<h/l>` Left/Right
* `<H/L>` Dash Left/Dash Right
* `<q>` Quit the Game
* `<r>` Reset
