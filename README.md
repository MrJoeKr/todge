# todge. 

Terminal Dodge.

<img width="1265" height="679" alt="todge" src="https://github.com/user-attachments/assets/cd9e941e-db62-4103-90c8-6301c0c700bd" />

You are `@`.

`■`s are falling on you.

Dodge `■`s to survive. 

`■`s speed up as the game progresses.

The higher altitude you have, the faster the ultimate ability recharges.

Survive as long as you can.

## Setup

Using [cargo](https://rust-lang.org/learn/get-started/):
```bash
cargo run
```

## Controls
Default controls. Can be changed in `src/config/keybinds.rs`:
* `<i/k>` Up/Down
* `<j/l>` Left/Right
* `<J/L>` Dash Left/Dash Right (shift + the key)
* `<SPACE>` Ultimate ability (invincibility for a short period of time)
* `<q>` Quit the Game
* `<r>` Restart the Game
